# Fruit Sales Analysis

## Project Overview

This project uses Python and Jupyter Notebook to analyze monthly fruit sales data.

The project demonstrates basic data analysis and visualization using pandas and matplotlib.

## Project Files

- `fruit_sales_analysis.ipynb` - The main Jupyter Notebook containing the analysis, calculations, and charts.
- `README.md` - Project documentation and running instructions.
- `requirements.txt` - Python packages required to run the project.

## Analysis

The notebook includes:

- Data creation and inspection
- Missing-value checking
- Total sales calculation
- Average monthly sales calculation
- Maximum monthly sales calculation
- Identification of the month with the highest total sales
- Monthly sales trend visualization
- Comparison of total sales by fruit

## How to Run

1. Install Python.
2. Install the required packages:

```bash
pip install -r requirements.txt
3. Open fruit_sales_analysis.ipynb using Jupyter Notebook.
4. Run the cells from top to bottom.
Reproducibility

The dataset is included directly in the Jupyter Notebook, so no external data download is required.

The required Python packages are listed in requirements.txt.
